## 前言

OpenClaw 作为目前最受欢迎的开源 AI 助手框架之一，其部署方式非常灵活——无论你是想在本地笔记本上运行，还是部署到云服务器上为团队提供服务，甚至是用 Docker 构建生产级别的高可用环境，OpenClaw 都能满足你的需求。

本文将覆盖所有主流的部署方式，帮助你选择最适合自己场景的方案。

## 方式一：本地快速安装

这是最简单的部署方式，适合个人学习和体验。

### 环境准备

确保你的系统已安装以下软件：

- **Node.js 18+**：推荐使用 nvm 管理 Node.js 版本
- **Git**：用于拉取项目代码
- **npm 或 yarn**：包管理工具

### 安装步骤

```bash
# 使用 npm 全局安装
npm install -g @openclaw/cli

# 验证安装
openclaw --version

# 初始化配置
openclaw init
```

初始化时系统会询问你几个关键配置项：

1. **默认模型选择**：推荐选择 GPT-4 或同等级别的模型
2. **API 密钥**：输入你的模型服务 API Key
3. **工作目录**：选择 OpenClaw 的默认工作目录
4. **语言偏好**：选择「简体中文」

配置完成后，运行 `openclaw chat` 即可开始使用。

## 方式二：Docker 部署

Docker 部署适合需要隔离环境或在服务器上运行的场景。

```bash
# 拉取官方镜像
docker pull openclaw/openclaw:latest

# 启动容器
docker run -d \
  --name openclaw \
  -p 8080:8080 \
  -v $(pwd)/data:/app/data \
  -e OPENCLAW_API_KEY=your-api-key \
  openclaw/openclaw:latest
```

启动后访问 `http://localhost:8080` 即可使用 Web 界面。

## 方式三：Docker Compose 生产部署

对于生产环境，推荐使用 Docker Compose 进行编排部署：

```yaml
version: "3.8"
services:
  openclaw:
    image: openclaw/openclaw:latest
    restart: always
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
      - ./config:/app/config
    environment:
      - OPENCLAW_API_KEY=${API_KEY}
      - OPENCLAW_ENV=production
      - OPENCLAW_LOG_LEVEL=info
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8080/health"]
      interval: 30s
      timeout: 10s
      retries: 3

  redis:
    image: redis:7-alpine
    restart: always
    volumes:
      - redis_data:/data

volumes:
  redis_data:
```

```bash
# 启动服务
docker compose up -d

# 查看日志
docker compose logs -f openclaw
```

## 方式四：云服务器一键部署

OpenClaw 官方提供了主流云平台的一键部署脚本：

### 阿里云 ECS

```bash
curl -fsSL https://deploy.openclaw.dev/aliyun | bash
```

### 腾讯云 CVM

```bash
curl -fsSL https://deploy.openclaw.dev/tencent | bash
```

### AWS EC2

```bash
curl -fsSL https://deploy.openclaw.dev/aws | bash
```

这些脚本会自动完成服务器环境配置、OpenClaw 安装、Nginx 反向代理设置和 SSL 证书申请。

## 部署后配置

无论使用哪种部署方式，完成安装后都建议进行以下配置：

### 安全加固

```bash
# 设置访问密码
openclaw config set auth.enabled true
openclaw config set auth.password "your-strong-password"

# 启用 HTTPS（如果使用 Web 界面）
openclaw config set server.ssl.enabled true
```

### 性能优化

```bash
# 启用响应缓存
openclaw config set cache.enabled true

# 设置并发限制
openclaw config set server.max_connections 50
```

## 常见问题排查

如果遇到问题，运行自检命令：

```bash
openclaw doctor
```

常见问题及解决方案：

- **API 连接超时**：检查网络环境，确保能访问模型服务的 API 地址
- **内存不足**：将 Node.js 内存限制调高，`export NODE_OPTIONS="--max-old-space-size=4096"`
- **端口冲突**：修改配置文件中的端口号，或停止占用端口的其他服务
