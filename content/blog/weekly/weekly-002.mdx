## 本周头条

### 社区技能包大爆发！一周新增 15 个高质量 Skill

本周是 OpenClaw 社区历史上技能包增长最快的一周。ClawHub 平台在短短七天内新增了 15 个社区贡献的技能包，覆盖了开发工具、内容创作、数据分析、生活效率和教育学习五大领域。截至本周末，ClawHub 上的技能包总数已达到 127 个，较上月增长了 34%。

这波爆发式增长主要得益于三个因素：

**Skill SDK 2.0 的发布**：新版 SDK 大幅简化了技能包的开发流程。开发者不再需要手写复杂的接口定义文件，SDK 提供了交互式脚手架工具，只需回答几个问题就能生成完整的项目模板。根据社区反馈，一个中等复杂度的技能包开发时间从原来的 2-3 天缩短到了 4-6 小时。

**社区开发者激励计划启动**：本月初启动的「Skill Builder 计划」为优秀的技能包开发者提供现金奖励和推广资源。首批 10 位入选的开发者已经获得了总计 5 万元的奖金，其中 3 位开发者的作品还被推荐到了 ClawHub 首页。

**企业需求驱动**：随着越来越多的企业开始试用 OpenClaw，来自企业场景的需求大量涌现，刺激了开发者社区的创作热情。本周新增的 15 个技能包中，有 6 个直接来源于企业用户的需求反馈。

这是一个非常积极的信号——OpenClaw 的生态正在进入正向循环。更多的技能包意味着更丰富的使用场景，更丰富的场景会吸引更多用户，更多用户则会催生更多的技能包开发需求。

## Top 5 新 Skill 推荐

我们从本周新增的 15 个技能包中精选了 5 个最值得关注的，涵盖不同使用场景：

### 1. @productivity/meeting-minutes（智能会议纪要）

**开发者**：@chenwei | **星标数**：286 | **安装量**：1,420

这是本周下载量最高的技能包。它可以实时监听会议录音（支持腾讯会议、飞书、Zoom），自动生成结构化的会议纪要，包括议题摘要、决策事项、待办任务和负责人分配。最让人惊艳的是它的多人发言识别能力，能够准确区分不同发言者并标注姓名。

```bash
openclaw skill install @productivity/meeting-minutes

# 使用示例
openclaw run @productivity/meeting-minutes --input ./meeting-record.mp3 --output ./minutes.md --format structured
```

支持的输出格式包括 Markdown、Notion 页面和飞书文档，可以无缝接入现有的工作流。

### 2. @devtools/api-mocker（API Mock 服务器）

**开发者**：@liuyang | **星标数**：198 | **安装量**：876

前端开发者的效率神器。只需要提供 API 文档（支持 OpenAPI/Swagger 格式），这个技能包就能自动生成一个功能完整的 Mock 服务器，返回符合接口定义的模拟数据。更厉害的是，它还能根据接口的语义生成合理的测试数据，比如用户名字段会生成真实的中文姓名，而不是随机字符串。

```bash
openclaw skill install @devtools/api-mocker

# 使用示例
openclaw run @devtools/api-mocker --spec ./openapi.yaml --port 3001
```

### 3. @content/xiaohongshu-writer（小红书爆款文案生成器）

**开发者**：@linxiaomei | **星标数**：412 | **安装量**：2,135

本周的星标之王。针对小红书平台的内容创作需求，这个技能包可以根据产品信息和目标受众自动生成高质量的种草文案。它内置了对 500+ 篇热门笔记的风格分析模型，能够模仿不同类型的爆款写作风格。输出包括标题（含 emoji 优化）、正文、标签推荐和最佳发布时间建议。

```bash
openclaw skill install @content/xiaohongshu-writer

# 使用示例
openclaw run @content/xiaohongshu-writer --product "便携式筋膜枪" --audience "健身爱好者" --style "真实体验分享"
```

### 4. @data/sql-translator（自然语言转 SQL）

**开发者**：@wangdong | **星标数**：167 | **安装量**：734

数据分析师的好帮手。连接你的数据库（支持 MySQL、PostgreSQL、SQLite），用自然语言描述你的查询需求，自动生成准确的 SQL 查询语句。它会先读取数据库的表结构和字段注释，确保生成的查询准确匹配你的数据模型。还内置了 SQL 性能分析功能，会提示可能存在的性能瓶颈并给出优化建议。

```bash
openclaw skill install @data/sql-translator

# 使用示例
openclaw run @data/sql-translator --db "postgresql://localhost/mydb" --query "找出上个月消费金额最高的前10位用户及其购买的商品类别"
```

### 5. @education/flashcard-maker（智能闪卡生成器）

**开发者**：@zhoujie | **星标数**：145 | **安装量**：623

学习利器。输入任何学习材料（教材 PDF、课程笔记、论文），自动生成间隔重复（Spaced Repetition）闪卡，支持导出为 Anki 格式。它能智能提取关键知识点，生成问答对，并根据知识点的难度和关联性自动安排复习计划。

```bash
openclaw skill install @education/flashcard-maker

# 使用示例
openclaw run @education/flashcard-maker --input ./chapter3.pdf --format anki --lang zh-CN
```

**作者**：@tangyi | **阅读量**：1,950 | **收藏数**：278
