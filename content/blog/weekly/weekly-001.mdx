## 新 Skill 推荐

本周 ClawHub 上新了几个非常实用的技能包，我们精选了三个推荐给大家：

### 1. @analytics/data-dashboard（数据看板生成器）

由社区开发者 @zhangsan 贡献。这个技能可以读取你的数据文件（支持 CSV、JSON、Excel），自动生成交互式数据看板。支持柱状图、折线图、饼图等多种图表类型，并且可以导出为 HTML 文件，方便分享给团队。

安装命令：`openclaw skill install @analytics/data-dashboard`

### 2. @content/wechat-formatter（微信公众号排版助手）

写公众号文章的同学有福了！这个技能可以将 Markdown 格式的文章自动转换为微信公众号兼容的富文本格式，支持代码高亮、自定义主题色、自动添加引用样式等功能。

安装命令：`openclaw skill install @content/wechat-formatter`

### 3. @devtools/git-autopilot（Git 自动驾驶）

自动分析代码变更，生成规范的 commit message，智能处理分支合并冲突。特别适合团队协作场景，确保 Git 历史记录清晰规范。

安装命令：`openclaw skill install @devtools/git-autopilot`

## 本周技巧

### 技巧一：使用管道符组合多个命令

你知道吗？在 OpenClaw 中你可以使用管道符 `|` 来组合多个操作：

```bash
> 读取 ./data/users.json | 筛选出最近7天注册的用户 | 按注册时间排序 | 导出为 CSV
```

这种链式操作可以大幅简化复杂的数据处理流程。

### 技巧二：用 @mention 快速引用文件

在对话中直接使用 `@文件名` 可以快速引用文件内容，无需输入完整路径：

```bash
> 请比较 @config.yaml 和 @config.example.yaml 的差异
```

### 技巧三：历史对话搜索

使用 `Ctrl+R` 快捷键可以搜索历史对话记录，快速找到之前的操作和结果，避免重复输入。
