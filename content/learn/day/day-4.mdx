## 让 AI 连接真实世界

前三天我们学习了对话技巧和文件操作，但这些都是在本地完成的。今天，我们将解锁 OpenClaw 最强大的能力之一——联网。让你的 AI 助手能够实时获取互联网信息，调用外部服务。

### 联网搜索

OpenClaw 内置了强大的联网搜索引擎，可以实时获取最新的网络信息。这意味着它不再受训练数据时间的限制。

#### 基本搜索

```bash
> 搜索一下 2026 年最流行的前端框架有哪些

> 帮我查找 OpenClaw 最新版本的更新日志
```

OpenClaw 会自动选择合适的搜索引擎，获取结果并进行智能摘要，给你最精炼的答案。

#### 深度搜索

当你需要更全面的信息时，可以使用深度搜索模式：

```bash
> /search --deep "Docker Compose v3 和 v2 的区别"
```

深度搜索会访问多个来源，交叉验证信息，并给出带引用来源的完整报告。

### 网页内容抓取

除了搜索，OpenClaw 还能直接抓取和解析网页内容：

```bash
> 请访问 https://example.com/docs/api 并提取 API 文档的核心内容

> 抓取 https://news.example.com 的今日头条，整理成中文摘要
```

这个功能在以下场景中特别有用：

- **竞品分析**：快速浏览竞争对手的产品页面
- **文档查阅**：直接从官方文档获取最新信息
- **内容聚合**：从多个来源收集和整理信息

### API 调用

OpenClaw 支持直接调用外部 API，这让它的能力边界大大扩展。

#### 配置 API 连接

在 Workspace 配置中添加 API 设置：

```yaml
apis:
  weather:
    base_url: "https://api.weather.com/v1"
    auth:
      type: bearer
      token: "${WEATHER_API_KEY}"
  github:
    base_url: "https://api.github.com"
    auth:
      type: token
      token: "${GITHUB_TOKEN}"
```

#### 使用 API

配置完成后，你可以在对话中自然地调用这些 API：

```bash
> 查一下北京今天的天气情况

> 获取我的 GitHub 仓库列表，按星标数排序
```

OpenClaw 会自动选择合适的 API 端点，构造请求参数，解析返回结果。

### 实战案例：信息聚合助手

让我们用今天学到的知识做一个实际应用——创建一个每日技术信息聚合：

```bash
> 请帮我完成以下任务：
  1. 搜索今天 Hacker News 的热门话题 Top 5
  2. 搜索今天 GitHub Trending 的热门 Python 项目 Top 3
  3. 查询 OpenClaw 的 GitHub 仓库最新的 3 个 Issue
  4. 将以上信息整合成一份简洁的日报，保存为 ./daily-tech-report.md
```

这个例子展示了联网搜索和文件操作的组合使用，仅需一条指令就能完成平时需要花费 30 分钟的信息收集工作。

### 安全注意事项

使用联网功能时，请注意以下安全事项：

- **API 密钥管理**：将敏感信息存储在环境变量中，不要硬编码
- **请求频率**：注意 API 的调用频率限制，避免被封禁
- **数据隐私**：不要在搜索中包含敏感的个人或公司信息
- **结果验证**：联网获取的信息不一定完全准确，重要决策前请人工验证
