## 前言

飞书和钉钉是国内企业市场占有率最高的两大通讯协作平台。飞书以其产品体验和开放能力著称，深受互联网和科技企业青睐；钉钉则凭借阿里生态和庞大的企业用户基数，在中小企业市场占据主导地位。

将 OpenClaw AI Agent 接入这两个平台，可以让团队成员在日常使用的办公工具中直接与 AI 交互，实现消息自动化、审批提醒、日程管理等功能。本教程将分别详解两个平台的接入方案，并在最后进行横向对比，帮助你做出最佳选择。

## 一、飞书自定义应用创建

### 1.1 注册飞书开放平台

1. 访问 [飞书开放平台](https://open.feishu.cn/)
2. 使用飞书账号登录（需要管理员权限或开发者权限）
3. 进入开发者后台

### 1.2 创建企业自建应用

1. 点击「创建企业自建应用」
2. 填写应用信息：
   - 应用名称：`OpenClaw AI 助手`
   - 应用描述：基于 OpenClaw 的 AI Agent 智能助手
   - 应用图标：上传你的应用图标
3. 创建完成后进入应用管理页面

### 1.3 获取凭证

在「凭证与基础信息」页面获取：

```
App ID:     cli_xxxxxxxxxxxxxxxxx
App Secret: xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

### 1.4 配置应用能力

在「添加应用能力」中启用以下功能：

1. **机器人**：在群组和私聊中作为 Bot 交互（必须启用）
2. **网页应用**（可选）：提供 OpenClaw Web 界面入口
3. **小程序**（可选）：移动端轻量入口

### 1.5 配置事件订阅

1. 进入「事件订阅」页面
2. 设置请求地址（Webhook URL）：`https://your-domain.com/webhook/feishu`
3. 添加需要订阅的事件：
   - `im.message.receive_v1`：接收消息
   - `im.chat.member.bot.added_v1`：Bot 被添加到群
   - `im.chat.member.bot.deleted_v1`：Bot 被移除出群
4. 保存并等待飞书验证回调地址

### 1.6 申请权限并发布

在「权限管理」中申请所需权限：

```
im:message                   # 发送和接收消息
im:message.group_at_msg      # 接收群聊 @Bot 消息
im:message.p2p_msg           # 接收私聊消息
im:chat                      # 获取群信息
contact:user.base            # 获取用户基本信息
approval:approval            # 审批相关操作
calendar:calendar            # 日历相关操作
```

完成权限申请后，在「版本管理与发布」中创建版本并提交发布，由管理员在飞书管理后台审批上线。

## 二、飞书消息推送

### 2.1 获取 Tenant Access Token

飞书 API 使用 Tenant Access Token 进行鉴权，有效期 2 小时。

```python
import requests
import time

class FeishuClient:
    """飞书 API 客户端"""

    BASE_URL = "https://open.feishu.cn/open-apis"

    def __init__(self, app_id, app_secret):
        self.app_id = app_id
        self.app_secret = app_secret
        self._tenant_token = None
        self._token_expires = 0

    def get_tenant_access_token(self):
        """获取 tenant_access_token"""
        if self._tenant_token and time.time() < self._token_expires:
            return self._tenant_token

        url = f"{self.BASE_URL}/auth/v3/tenant_access_token/internal"
        payload = {
            "app_id": self.app_id,
            "app_secret": self.app_secret
        }
        resp = requests.post(url, json=payload).json()
        if resp.get("code") == 0:
            self._tenant_token = resp["tenant_access_token"]
            self._token_expires = time.time() + resp["expire"] - 300
            return self._tenant_token
        raise Exception(f"获取 token 失败: {resp}")

    def _headers(self):
        return {
            "Authorization": f"Bearer {self.get_tenant_access_token()}",
            "Content-Type": "application/json; charset=utf-8"
        }

    def send_text(self, receive_id, text, receive_id_type="open_id"):
        """发送文本消息"""
        url = f"{self.BASE_URL}/im/v1/messages?receive_id_type={receive_id_type}"
        payload = {
            "receive_id": receive_id,
            "msg_type": "text",
            "content": f'{{"text": "{text}"}}'
        }
        return requests.post(url, headers=self._headers(), json=payload).json()

    def send_rich_text(self, receive_id, title, content_blocks, receive_id_type="open_id"):
        """发送富文本消息"""
        import json
        url = f"{self.BASE_URL}/im/v1/messages?receive_id_type={receive_id_type}"
        post_content = {
            "zh_cn": {
                "title": title,
                "content": content_blocks
            }
        }
        payload = {
            "receive_id": receive_id,
            "msg_type": "post",
            "content": json.dumps({"post": post_content})
        }
        return requests.post(url, headers=self._headers(), json=payload).json()

    def send_card(self, receive_id, card_content, receive_id_type="open_id"):
        """发送消息卡片"""
        url = f"{self.BASE_URL}/im/v1/messages?receive_id_type={receive_id_type}"
        payload = {
            "receive_id": receive_id,
            "msg_type": "interactive",
            "content": card_content
        }
        return requests.post(url, headers=self._headers(), json=payload).json()


# 使用示例
client = FeishuClient(
    app_id="cli_abcdef1234567890",
    app_secret="your_app_secret"
)

# 发送文本消息
client.send_text("ou_abcdef1234567890", "你好，这是来自 OpenClaw 的消息")
```

### 3.2 处理卡片回调

当用户点击卡片上的按钮时，飞书会向你配置的回调地址发送请求：

```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route("/webhook/feishu", methods=["POST"])
def feishu_webhook():
    data = request.json

    # 处理 URL 验证请求
    if "challenge" in data:
        return jsonify({"challenge": data["challenge"]})

    # 处理卡片回调
    if data.get("type") == "interactive":
        action = data.get("action", {})
        value = json.loads(action.get("value", "{}"))

        if value.get("action") == "rerun":
            task_id = value.get("task_id")
            # 触发任务重新执行
            rerun_task(task_id)
            return jsonify({"toast": {"type": "success", "content": "任务已重新执行"}})

        elif value.get("action") == "approve":
            approval_id = value.get("id")
            approve_request(approval_id)
            return jsonify({"toast": {"type": "success", "content": "已同意"}})

    # 处理消息事件
    if data.get("header", {}).get("event_type") == "im.message.receive_v1":
        event = data.get("event", {})
        message = event.get("message", {})
        handle_message(message)

    return jsonify({"code": 0})
```

```python
from datetime import datetime, timedelta

def create_calendar_event(client, calendar_id, summary, start_time, end_time, attendees=None):
    """创建飞书日历事件"""
    url = f"{client.BASE_URL}/calendar/v4/calendars/{calendar_id}/events"
    payload = {
        "summary": summary,
        "start_time": {"timestamp": str(int(start_time.timestamp()))},
        "end_time": {"timestamp": str(int(end_time.timestamp()))},
        "visibility": "default",
        "attendee_ability": "can_modify_event",
    }
    if attendees:
        payload["attendees"] = [
            {"type": "user", "user_id": uid} for uid in attendees
        ]
    return requests.post(url, headers=client._headers(), json=payload).json()

def get_today_events(client, calendar_id):
    """获取今天的日程列表"""
    today_start = datetime.now().replace(hour=0, minute=0, second=0)
    today_end = today_start + timedelta(days=1)

    url = f"{client.BASE_URL}/calendar/v4/calendars/{calendar_id}/events"
    params = {
        "start_time": str(int(today_start.timestamp())),
        "end_time": str(int(today_end.timestamp())),
    }
    return requests.get(url, headers=client._headers(), params=params).json()
```

## 六、钉钉群机器人

### 6.1 创建群机器人

### 6.2 群机器人消息推送

```python
import requests
import time
import hmac
import hashlib
import base64
import urllib.parse

class DingTalkRobot:
    """钉钉群机器人"""

    def __init__(self, webhook_url, secret=None):
        self.webhook_url = webhook_url
        self.secret = secret

    def _get_sign_url(self):
        """生成加签 URL"""
        if not self.secret:
            return self.webhook_url

        timestamp = str(round(time.time() * 1000))
        string_to_sign = f"{timestamp}\n{self.secret}"
        hmac_code = hmac.new(
            self.secret.encode('utf-8'),
            string_to_sign.encode('utf-8'),
            digestmod=hashlib.sha256
        ).digest()
        sign = urllib.parse.quote_plus(base64.b64encode(hmac_code))
        return f"{self.webhook_url}&timestamp={timestamp}&sign={sign}"

    def send_text(self, content, at_mobiles=None, at_all=False):
        """发送文本消息"""
        payload = {
            "msgtype": "text",
            "text": {"content": content},
            "at": {"atMobiles": at_mobiles or [], "isAtAll": at_all}
        }
        return requests.post(self._get_sign_url(), json=payload).json()

    def send_markdown(self, title, text, at_mobiles=None):
        """发送 Markdown 消息"""
        payload = {
            "msgtype": "markdown",
            "markdown": {"title": title, "text": text},
            "at": {"atMobiles": at_mobiles or [], "isAtAll": False}
        }
        return requests.post(self._get_sign_url(), json=payload).json()

    def send_action_card(self, title, text, buttons):
        """发送 ActionCard 消息"""
        payload = {
            "msgtype": "actionCard",
            "actionCard": {
                "title": title,
                "text": text,
                "btnOrientation": "0",   # 0 竖排，1 横排
                "btns": [
                    {"title": btn["title"], "actionURL": btn["url"]}
                    for btn in buttons
                ]
            }
        }
        return requests.post(self._get_sign_url(), json=payload).json()

    def send_feed_card(self, links):
        """发送 FeedCard 消息（链接列表卡片）"""
        payload = {
            "msgtype": "feedCard",
            "feedCard": {
                "links": [
                    {
                        "title": link["title"],
                        "messageURL": link["url"],
                        "picURL": link.get("pic", "")
                    }
                    for link in links
                ]
            }
        }
        return requests.post(self._get_sign_url(), json=payload).json()
```

## 七、钉钉工作通知

工作通知直接推送到员工的「工作通知」频道，打开率远高于群消息。

```python
class DingTalkAppClient:
    """钉钉企业内部应用客户端"""

    BASE_URL = "https://oapi.dingtalk.com"

    def __init__(self, app_key, app_secret, agent_id):
        self.app_key = app_key
        self.app_secret = app_secret
        self.agent_id = agent_id
        self._token = None
        self._token_expires = 0

    def get_access_token(self):
        """获取 access_token"""
        if self._token and time.time() < self._token_expires:
            return self._token

        url = f"{self.BASE_URL}/gettoken"
        params = {"appkey": self.app_key, "appsecret": self.app_secret}
        resp = requests.get(url, params=params).json()
        if resp.get("errcode") == 0:
            self._token = resp["access_token"]
            self._token_expires = time.time() + resp["expires_in"] - 300
            return self._token
        raise Exception(f"获取 token 失败: {resp}")

    def send_work_notification(self, user_ids, msg):
        """发送工作通知"""
        url = f"{self.BASE_URL}/topapi/message/corpconversation/asyncsend_v2"
        params = {"access_token": self.get_access_token()}
        payload = {
            "agent_id": self.agent_id,
            "userid_list": ",".join(user_ids),
            "msg": msg
        }
        return requests.post(url, params=params, json=payload).json()
```

## 八、平台对比与最佳实践

### 8.1 功能对比

| 功能维度 | 飞书 | 钉钉 |
|---------|------|------|
| 消息卡片 | 互动卡片（非常丰富） | ActionCard（较简单） |
| 群机器人 | Webhook + 应用机器人 | 自定义机器人 + 应用机器人 |
| 审批集成 | API 完善，自定义审批流 | API 完善，OA 生态成熟 |
| 日历集成 | 原生日历 API | 需对接第三方 |
| 文档协作 | 飞书文档 API（强大） | 钉钉文档 API |
| API 文档质量 | 优秀 | 良好 |
| 典型用户 | 互联网/科技企业 | 中小企业/传统行业 |
| 消息频率限制 | 较宽松 | 群机器人每分钟 20 条 |

### 8.2 选择建议

- **团队已在使用飞书**：直接选飞书集成，充分利用互动卡片和文档 API
- **团队已在使用钉钉**：选钉钉集成，群机器人快速上手
- **两个平台都在用**：使用 OpenClaw 统一消息网关同时接入

## 九、常见问题与排错

### 9.1 飞书常见问题

**事件订阅验证失败：** 确保你的 Webhook 端点能正确返回 `challenge` 值。

**Token 过期导致消息发送失败：** 飞书的 tenant_access_token 有效期为 2 小时，务必实现自动续期。

**消息卡片渲染异常：** 检查 JSON 格式是否正确，可使用飞书的 [卡片搭建工具](https://open.feishu.cn/tool/cardbuilder) 在线预览。

### 9.2 钉钉常见问题

**群机器人消息频率限制：** 每个机器人每分钟最多发送 20 条消息，超过返回错误码 130101。使用消息队列控制频率。

**签名验证失败：** 确保时间戳误差不超过 1 小时，签名算法正确使用 HMAC-SHA256。

**工作通知到达率低：** 检查是否超过每日推送上限（单聊 500 条/天），确保用户未关闭工作通知。

## 总结

飞书和钉钉各有所长。飞书在开发者体验、互动卡片和文档集成上更具优势；钉钉在用户基数、OA 生态和审批流程上更为成熟。将 OpenClaw 接入这两个平台后，团队成员可以在熟悉的办公工具中直接使用 AI 能力，显著提升工作效率。

建议从群机器人开始入手（零成本、最快速），验证场景价值后再逐步扩展到应用级集成。
