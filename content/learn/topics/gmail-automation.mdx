## 前言

邮件依然是商务沟通的核心渠道。对于每天收到 50-200 封邮件的职场人来说，筛选重要信息、及时回复和跟进是巨大的时间消耗。据统计，职场人平均每天花费 2.6 小时处理邮件，其中大量时间花在了低价值的筛选和分类上。

通过将 OpenClaw 与 Gmail 集成，你可以实现邮件的自动摘要、智能分类、优先级标记、自动回复和跟进提醒，将每天的邮件处理时间从 2 小时以上压缩到 15 分钟。

## 一、Google API 与 OAuth 配置

### 1.1 创建 Google Cloud 项目

1. 访问 [Google Cloud Console](https://console.cloud.google.com)
2. 点击顶部导航栏的项目选择器，选择「新建项目」
3. 项目名称：`OpenClaw Mail Assistant`
4. 创建完成后，确保在该项目下进行后续操作

### 1.2 启用 Gmail API

1. 在左侧菜单中选择「API 和服务」→「库」
2. 搜索「Gmail API」并点击进入
3. 点击「启用」按钮
4. 同时建议启用「Google Calendar API」（后续日历集成会用到）

### 1.3 配置 OAuth 同意屏幕

1. 进入「API 和服务」→「OAuth 同意屏幕」
2. 选择用户类型：
   - **外部**：适合个人 Gmail 用户
   - **内部**：适合 Google Workspace 组织内部
3. 填写应用信息：
   - 应用名称：`OpenClaw Mail Assistant`
   - 用户支持邮箱：你的邮箱
   - 开发者联系信息：你的邮箱
4. 添加 Scopes（权限范围）：

```
https://www.googleapis.com/auth/gmail.readonly      # 读取邮件
https://www.googleapis.com/auth/gmail.send           # 发送邮件
https://www.googleapis.com/auth/gmail.modify         # 修改标签等
https://www.googleapis.com/auth/gmail.labels          # 管理标签
```

### 1.4 创建 OAuth 客户端凭据

1. 进入「API 和服务」→「凭据」
2. 点击「创建凭据」→「OAuth 客户端 ID」
3. 应用类型选择「桌面应用」
4. 名称：`OpenClaw Desktop Client`
5. 创建完成后，下载 JSON 文件并保存为 `credentials.json`

### 1.5 完成 OAuth 授权

```bash
# 安装 Gmail Skill
openclaw skill install gmail

# 配置 OAuth 凭据
openclaw gmail auth --credentials ./credentials.json

# 浏览器会自动打开 Google 授权页面
# 登录你的 Gmail 账号并授权
# 授权完成后 token 会自动保存
```

授权完成后，token 文件保存在 `~/.openclaw/skills/gmail/token.json`，请确保安全：

```bash
# 设置文件权限
chmod 600 ~/.openclaw/skills/gmail/credentials.json
chmod 600 ~/.openclaw/skills/gmail/token.json

# 添加到 .gitignore
echo "credentials.json" >> .gitignore
echo "token.json" >> .gitignore
```

### 3.3 邮件摘要 API 实现

```python
from google.oauth2.credentials import Credentials
from google_auth_oauthlib.flow import InstalledAppFlow
from google.auth.transport.requests import Request
from googleapiclient.discovery import build
import base64
import json

class GmailClient:
    """Gmail API 客户端"""

    SCOPES = [
        'https://www.googleapis.com/auth/gmail.readonly',
        'https://www.googleapis.com/auth/gmail.send',
        'https://www.googleapis.com/auth/gmail.modify',
    ]

    def __init__(self, credentials_path, token_path):
        self.credentials_path = credentials_path
        self.token_path = token_path
        self.service = self._build_service()

    def _build_service(self):
        """构建 Gmail API 服务"""
        creds = None
        try:
            creds = Credentials.from_authorized_user_file(self.token_path, self.SCOPES)
        except FileNotFoundError:
            pass

        if not creds or not creds.valid:
            if creds and creds.expired and creds.refresh_token:
                creds.refresh(Request())
            else:
                flow = InstalledAppFlow.from_client_secrets_file(
                    self.credentials_path, self.SCOPES
                )
                creds = flow.run_local_server(port=0)

            with open(self.token_path, 'w') as token:
                token.write(creds.to_json())

        return build('gmail', 'v1', credentials=creds)

    def fetch_emails(self, query="is:unread", max_results=50):
        """获取邮件列表"""
        results = self.service.users().messages().list(
            userId='me', q=query, maxResults=max_results
        ).execute()

        messages = results.get('messages', [])
        emails = []
        for msg in messages:
            detail = self.service.users().messages().get(
                userId='me', id=msg['id'], format='metadata',
                metadataHeaders=['From', 'Subject', 'Date', 'To', 'Cc']
            ).execute()

            headers = {h['name']: h['value'] for h in detail.get('payload', {}).get('headers', [])}
            emails.append({
                'id': msg['id'],
                'thread_id': detail.get('threadId'),
                'from': headers.get('From', ''),
                'to': headers.get('To', ''),
                'cc': headers.get('Cc', ''),
                'subject': headers.get('Subject', ''),
                'date': headers.get('Date', ''),
                'snippet': detail.get('snippet', ''),
                'labels': detail.get('labelIds', []),
                'has_attachments': any(
                    p.get('filename') for p in detail.get('payload', {}).get('parts', [])
                )
            })
        return emails

    def get_email_body(self, message_id):
        """获取邮件正文"""
        msg = self.service.users().messages().get(
            userId='me', id=message_id, format='full'
        ).execute()

        payload = msg.get('payload', {})
        body = ''

        if payload.get('body', {}).get('data'):
            body = base64.urlsafe_b64decode(payload['body']['data']).decode('utf-8')
        elif payload.get('parts'):
            for part in payload['parts']:
                if part['mimeType'] == 'text/plain':
                    data = part.get('body', {}).get('data', '')
                    if data:
                        body = base64.urlsafe_b64decode(data).decode('utf-8')
                        break
        return body

    def add_label(self, message_id, label_names):
        """为邮件添加标签"""
        # 获取或创建标签
        label_ids = []
        existing_labels = self.service.users().labels().list(userId='me').execute()
        label_map = {l['name']: l['id'] for l in existing_labels.get('labels', [])}

        for name in label_names:
            if name in label_map:
                label_ids.append(label_map[name])
            else:
                # 创建新标签
                new_label = self.service.users().labels().create(
                    userId='me',
                    body={'name': name, 'labelListVisibility': 'labelShow'}
                ).execute()
                label_ids.append(new_label['id'])

        self.service.users().messages().modify(
            userId='me', id=message_id,
            body={'addLabelIds': label_ids}
        ).execute()

    def send_reply(self, message_id, thread_id, to, subject, body):
        """回复邮件"""
        from email.mime.text import MIMEText
        message = MIMEText(body, 'plain', 'utf-8')
        message['to'] = to
        message['subject'] = f"Re: {subject}"
        message['In-Reply-To'] = message_id
        message['References'] = message_id

        raw = base64.urlsafe_b64encode(message.as_bytes()).decode()
        self.service.users().messages().send(
            userId='me',
            body={'raw': raw, 'threadId': thread_id}
        ).execute()
```

## 四、智能分类与优先级

### 4.1 AI 驱动的邮件分类

```python
async def classify_email(gmail_client, openclaw_api, email):
    """使用 AI 对单封邮件进行智能分类"""

    classification = await openclaw_api.chat(f"""
    分析这封邮件的紧急程度和类型，返回 JSON 格式：

    发件人: {email['from']}
    主题: {email['subject']}
    摘要: {email['snippet']}
    收件人: {email['to']}
    抄送: {email['cc']}

    请返回：
    {{
        "priority": "high/medium/low",
        "category": "紧急/需要回复/FYI/订阅通知",
        "needs_reply": true/false,
        "reply_deadline": "建议回复时间（如 2 小时内/今天内/本周内）",
        "action_items": ["提取的待办事项列表"],
        "summary": "一句话中文摘要",
        "sentiment": "正面/中性/负面"
    }}
    """)

    result = json.loads(classification)

    # 根据分类结果添加 Gmail 标签
    label_prefix = "OpenClaw"
    labels = [f"{label_prefix}/{result['category']}"]
    if result['priority'] == 'high':
        labels.append(f"{label_prefix}/High Priority")

    gmail_client.add_label(email['id'], labels)

    return result


async def batch_classify_emails(gmail_client, openclaw_api, query="is:unread"):
    """批量分类未读邮件"""
    emails = gmail_client.fetch_emails(query=query)
    results = []

    for email in emails:
        result = await classify_email(gmail_client, openclaw_api, email)
        results.append({**email, **result})

        # 对高优先级邮件立即推送通知
        if result['priority'] == 'high':
            await send_urgent_notification(email, result)

    return results
```

```python
async def handle_attachment(gmail_client, openclaw_api, email):
    """处理邮件附件"""
    msg = gmail_client.service.users().messages().get(
        userId='me', id=email['id'], format='full'
    ).execute()

    attachments = []
    parts = msg.get('payload', {}).get('parts', [])

    for part in parts:
        filename = part.get('filename')
        if not filename:
            continue

        # 下载附件
        attachment_id = part['body'].get('attachmentId')
        if attachment_id:
            attachment = gmail_client.service.users().messages().attachments().get(
                userId='me', messageId=email['id'], id=attachment_id
            ).execute()

            data = base64.urlsafe_b64decode(attachment['data'])

            # AI 分类附件
            category = await openclaw_api.chat(f"""
            请对以下邮件附件进行分类，返回分类名称（发票/合同/报告/图片/其他）：
            文件名：{filename}
            发件人：{email['from']}
            邮件主题：{email['subject']}
            """)

            category = category.strip()

            # 保存到对应目录
            import os
            from datetime import datetime
            date_str = datetime.now().strftime("%Y/%m")
            save_dir = f"{os.environ['HOME']}/Documents/EmailAttachments/{category}/{date_str}"
            os.makedirs(save_dir, exist_ok=True)

            save_path = os.path.join(save_dir, filename)
            with open(save_path, 'wb') as f:
                f.write(data)

            attachments.append({
                "filename": filename,
                "category": category,
                "path": save_path,
                "size": len(data)
            })

    return attachments
```

## 八、隐私与安全

### 8.1 安全最佳实践

```yaml
# config/skills/gmail-security.yaml

security:
  # OAuth Token 管理
  oauth:
    # Token 文件权限必须设为 600
    file_permissions: "600"
    # 定期刷新 Token
    auto_refresh: true
    # Token 轮换周期
    rotation_days: 90

  # 数据处理
  data:
    # 邮件内容仅在本地处理
    local_processing: true
    # 发送给 AI 模型时脱敏
    redact_before_ai:
      enabled: true
      patterns:
        - type: "phone"
          replace: "[电话号码]"
        - type: "id_card"
          replace: "[身份证号]"
        - type: "bank_card"
          replace: "[银行卡号]"
        - type: "password"
          replace: "[密码已隐藏]"

    # 不处理的邮件标签
    skip_labels: ["CONFIDENTIAL", "机密"]

    # 邮件内容不写入日志
    log_content: false
    # 仅记录元数据
    log_metadata: true

  # 访问控制
  access:
    # 只允许读取，不允许删除
    allow_delete: false
    # 自动回复需要确认
    reply_require_confirmation: true
    # 敏感操作（如转发邮件）需要二次确认
    sensitive_actions_require_2fa: true
```
