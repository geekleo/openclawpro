## 前言

每天面对 100+ 封邮件，重要信息容易被淹没。OpenClaw 的 Gmail Skill 可以自动摘要邮件、智能分类、标记优先级，并在需要跟进时推送提醒，让你不再错过任何重要邮件。

## 一、Google API 配置

### 1. 创建 Google Cloud 项目

1. 访问 [Google Cloud Console](https://console.cloud.google.com)
2. 创建新项目：「OpenClaw Mail Assistant」
3. 启用 Gmail API：
   - 导航到「API 和服务」→「库」
   - 搜索「Gmail API」并启用

### 2. 配置 OAuth 2.0

```bash
# 创建 OAuth 客户端凭据
# 1. 进入「凭据」页面
# 2. 创建 OAuth 客户端 ID
# 3. 应用类型选择「桌面应用」
# 4. 下载 credentials.json
```

### 3. 授权流程

```bash
# 安装 Gmail Skill
openclaw skill install gmail

# 配置 OAuth
openclaw gmail auth --credentials ./credentials.json

# 浏览器会自动打开授权页面
# 授权后 token 会自动保存到 ~/.openclaw/skills/gmail/token.json
```

## 二、基础配置

```yaml
# ~/.openclaw/skills/gmail/config.yaml
gmail:
  auth:
    credentials_path: "${HOME}/.openclaw/skills/gmail/credentials.json"
    token_path: "${HOME}/.openclaw/skills/gmail/token.json"

  # 邮件检查频率
  check_interval: "5m"

  # 自动摘要配置
  summary:
    enabled: true
    max_length: 200  # 摘要最大字数
    language: "zh-CN"
    include_action_items: true

  # 分类规则
  classification:
    categories:
      - name: "紧急"
        rules: ["urgent", "ASAP", "紧急", "请立即"]
        priority: 1
      - name: "需要回复"
        rules: ["please reply", "请回复", "请确认", "what do you think"]
        priority: 2
      - name: "FYI"
        rules: ["FYI", "供参考", "周知"]
        priority: 3
      - name: "订阅/通知"
        rules: ["unsubscribe", "newsletter", "notification"]
        priority: 4

  # 跟进提醒
  follow_up:
    enabled: true
    default_remind_after: "24h"
    channels: ["telegram"]
```

## 三、自动邮件摘要

### 每日摘要

```yaml
name: daily_email_summary
schedule: "0 9 * * 1-5"  # 工作日早上 9 点
steps:
  - name: fetch_emails
    action: gmail.fetch
    params:
      query: "is:unread after:{{yesterday}}"
      max_results: 50

  - name: classify
    action: ai.classify
    params:
      items: "{{emails}}"
      categories: ["紧急", "需要回复", "FYI", "订阅通知"]

  - name: summarize
    action: ai.summarize
    prompt: |
      将以下邮件按优先级分类并生成中文摘要：

      {{classified_emails}}

      输出格式：
      🔴 紧急（需要立即处理）
      - [发件人] 主题：摘要（1-2句话）

      🟡 需要回复
      - [发件人] 主题：摘要 + 建议回复要点

      🟢 FYI（仅需了解）
      - [发件人] 主题：一句话摘要

      📊 数据概览：共 X 封新邮件，X 封需要处理

  - name: push
    action: telegram.send
    params:
      message: "📧 今日邮件摘要\n\n{{summary}}"
```

### 每周邮件报告

```yaml
name: weekly_email_report
schedule: "0 17 * * 5"
steps:
  - name: fetch_week_emails
    action: gmail.fetch
    params:
      query: "after:{{week_start}} before:{{week_end}}"

  - name: analyze
    action: ai.analyze
    prompt: |
      分析本周邮件数据：
      - 总收件数
      - 按发件人分组的统计
      - 高频主题/关键词
      - 未回复邮件列表
      - 平均回复时间

  - name: report
    action: notion.create_page
    params:
      database_id: "${EMAIL_REPORT_DB}"
      content: "{{analysis}}"
```

## 四、智能分类与优先级

### AI 驱动的智能分类

```yaml
name: smart_classify
trigger: gmail.new_email
steps:
  - name: analyze
    action: ai.classify
    params:
      content: "{{email.subject}} {{email.snippet}}"
      prompt: |
        分析这封邮件的紧急程度和类型：
        发件人: {{email.from}}
        主题: {{email.subject}}
        摘要: {{email.snippet}}

        返回 JSON：
        {
          "priority": "high/medium/low",
          "category": "类别",
          "needs_reply": true/false,
          "reply_deadline": "建议回复时间",
          "action_items": ["待办事项列表"]
        }

  - name: label
    action: gmail.add_label
    params:
      message_id: "{{email.id}}"
      labels: ["{{classification.priority}}", "{{classification.category}}"]

  - name: alert_if_urgent
    condition: "{{classification.priority}} == 'high'"
    action: telegram.send
    params:
      message: "🔴 紧急邮件！\n发件人：{{email.from}}\n主题：{{email.subject}}\n建议操作：{{classification.action_items}}"
```

## 六、跟进提醒配置

```yaml
name: follow_up_reminder
schedule: "0 10,15 * * 1-5"  # 每天 10:00 和 15:00 检查
steps:
  - name: check_unreplied
    action: gmail.fetch
    params:
      query: "is:sent after:{{2_days_ago}} -has:reply"

  - name: filter
    action: filter
    params:
      condition: "{{email.importance}} >= medium"

  - name: remind
    action: telegram.send
    params:
      message: |
        ⏰ 跟进提醒
        以下邮件已发送超过 48 小时未收到回复：
        {{#each unreplied_emails}}
        - 收件人：{{to}} | 主题：{{subject}} | 发送时间：{{sent_at}}
        {{/each}}

        建议操作：再次跟进或电话联系
```

```yaml
  - name: save_to_drive

```

## 八、隐私与安全

### 安全最佳实践

1. **最小权限原则**：OAuth 授权时只勾选必要的 Gmail 权限范围
2. **Token 保护**：`token.json` 文件权限设为 600，不要提交到版本控制
3. **定期轮换**：每 90 天刷新 OAuth Token
4. **审计日志**：开启操作日志记录所有邮件处理行为

```bash
# 设置 token 文件权限
chmod 600 ~/.openclaw/skills/gmail/token.json
chmod 600 ~/.openclaw/skills/gmail/credentials.json

# 添加到 .gitignore
echo "credentials.json" >> .gitignore
echo "token.json" >> .gitignore
```

### 数据处理原则

- 邮件内容只在本地处理，不上传到第三方服务器
- AI 模型处理使用 API 调用，遵循模型提供商的数据处理政策
- 敏感邮件（包含密码、个人信息等）自动跳过 AI 处理
