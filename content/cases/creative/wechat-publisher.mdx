# AI 自动写公众号并定时发布

> "以前一篇文章从选题到发布要4个小时，现在我只需要花20分钟审核和微调，剩下的全部自动化完成。" —— 公众号主理人 小陈

## 场景痛点

小陈是一位科技领域的自媒体人，运营着一个名为「科技前线站」的微信公众号，专注于 AI、数码产品和互联网行业分析。账号有约 3 万粉丝，属于垂直领域的中腰部账号。

在引入 OpenClaw 之前，小陈的内容生产流程是这样的：

**选题阶段（1小时）**：每天早上浏览科技媒体（36氪、虎嗅、极客公园、TechCrunch 等）、刷社交媒体热点、查看行业报告，从中筛选出值得写的话题。这个过程繁琐且容易遗漏热点。

**写作阶段（2-2.5小时）**：确定选题后开始写作。一篇 2000-3000 字的深度分析文章，从搜集资料、整理论据到完成初稿，通常需要 2 个小时以上。如果是涉及数据对比的内容，时间更长。

**配图与排版（30分钟）**：在各素材网站搜索合适的配图，调整文章排版格式，设计封面图，确保在手机端的阅读体验。

**发布与推广（30分钟）**：登录公众号后台上传文章，设置发布时间，同步到知乎、头条号等其他平台。

这意味着**一篇文章的完整产出周期约为 4-5 个小时**，按照每周 4 篇的更新频率，小陈每周要花 16-20 个小时在内容生产上。作为一个人运营的自媒体，这几乎是全部精力所在。

核心矛盾在于：**平台算法越来越青睐高频更新的账号，但个人创作者的产能有明确天花板**。小陈尝试过外包写手，但质量参差不齐且沟通成本高；也试过直接用 ChatGPT 写文章，但产出内容千篇一律、缺乏个人风格，读者一眼就能看出是 AI 写的。

## 解决方案

小陈用 OpenClaw 搭建了一套完整的内容自动化生产线，覆盖从选题到发布的全流程。与直接使用 AI 写作不同，这套系统的核心在于**融入了个人风格模板和质量把控机制**。

### 1. 智能选题引擎

系统每天自动抓取多个信息源的内容：
- **RSS 订阅**：36氪、虎嗅、极客公园、TechCrunch、The Verge 等 20+ 科技媒体
- **社交媒体**：微博科技榜、知乎热榜科技分区、Twitter/X 上的科技 KOL 动态
- **行业数据**：App Annie 应用排行变化、GitHub Trending、产品 Hunt 每日新品

AI 对采集到的信息进行分析，从三个维度评估选题价值：
- **热度分**：当前话题的讨论热度和趋势
- **匹配分**：与账号定位和读者画像的契合度
- **差异分**：市面上同类内容的饱和度，优先选择有差异化空间的话题

最终输出一份包含 5-8 个候选选题的清单，每个选题附带推荐角度和预估阅读量。

### 2. 风格化内容生成

这是整套系统最核心的模块。小陈花了两周时间，从自己过往发表的 200 多篇文章中提炼出了一套"写作风格指南"，包括：

- **语气风格**：理性分析为主，偶尔带点犀利吐槽，不用"震惊体"和"标题党"
- **文章结构**：开头用一个引发共鸣的场景或问题切入，中间用数据和案例论证，结尾给出自己的判断和展望
- **常用句式**：偏好短句和口语化表达，避免学术化长句
- **禁忌清单**：不用"赋能"、"颠覆"、"降维打击"等过度营销的词汇

这套风格指南被编码进 System Prompt 中，确保 AI 生成的内容能保持一致的个人风格。

### 3. 配图与排版

系统根据文章内容自动匹配配图：
- 从 Unsplash、Pexels 等免费图库按关键词搜索
- 自动生成数据图表（如果文章涉及数据对比）
- 按照预设的排版模板自动格式化内容

### 4. 定时发布

文章生成后，进入待审核队列。小陈每天花 20 分钟浏览审核，可以直接通过、标记修改或退回重写。审核通过的文章按照预设的发布时间表自动推送。

## 关键配置

```yaml
name: wechat-auto-publisher
description: 微信公众号内容自动化生产与发布系统
version: "3.0.0"

triggers:
  # 每天早上6点抓取热点并生成选题
  - type: cron
    schedule: "0 6 * * *"
    task: topic_generation

  # 每天上午8点开始内容生成
  - type: cron
    schedule: "0 8 * * *"
    task: content_generation

  # 工作日下午6点发布（公众号最佳打开时段）
  - type: cron
    schedule: "0 18 * * 1-5"
    task: publish

  # 周末上午10点发布
  - type: cron
    schedule: "0 10 * * 0,6"
    task: publish

settings:
  model: gpt-4o
  temperature: 0.7  # 适中温度，兼顾创造力和准确性
  max_tokens: 6000

data_sources:
  rss_feeds:
    - "https://36kr.com/feed"
    - "https://www.huxiu.com/rss/0.xml"
    - "https://feeds.feedburner.com/TechCrunch"
  social:
    weibo_topics: ["科技", "数码", "互联网"]
    zhihu_categories: ["科技", "人工智能", "数码"]
  refresh_interval: 3600  # 每小时刷新一次

topic_scoring:
  weights:
    hotness: 0.3
    relevance: 0.5
    uniqueness: 0.2
  min_score: 70      # 低于70分的选题自动过滤
  max_topics: 8      # 每天最多推荐8个选题

content_generation:
  style_prompt: |
    你是「科技前线站」公众号的主笔。写作风格要求如下：

    ## 语气
    - 理性、客观、有深度，像一位懂行的朋友在跟你聊天
    - 可以有适度的个人观点和判断，但要有数据支撑
    - 偶尔可以幽默吐槽，但不刻意搞笑

    ## 结构
    - 开头：用一个具体场景、问题或数据切入，3句话内抓住注意力
    - 正文：逻辑清晰，每个观点都有论据（数据、案例、对比）
    - 结尾：给出自己的判断和展望，不泛泛而谈

    ## 规范
    - 字数控制在 2000-3000 字
    - 段落不超过5行，保持手机阅读的舒适度
    - 每500字左右插入一个小标题
    - 禁用词汇：赋能、颠覆、降维打击、生态闭环、护城河

  article_template: |
    ## 标题要求
    - 15-25个字，信息量大，不用问号结尾
    - 包含核心关键词，有利于搜索

    ## 正文结构
    1. 引子（100-200字）
    2. 背景介绍（300-500字）
    3. 核心分析（800-1200字）
    4. 数据与案例（400-600字）
    5. 总结与展望（200-300字）

  quality_check:
    - originality_score: ">= 85%"    # 原创度不低于85%
    - readability_score: ">= 80"     # 可读性评分
    - fact_check: true                # 事实核查
    - sensitive_word_filter: true     # 敏感词过滤

publishing:
  platform: wechat_mp
  review_required: true    # 发布前需要人工审核
  review_notify:
    type: wechat
    template: "新文章待审核：{title}，预计发布时间：{publish_time}"
  auto_tags: true          # 自动添加文章标签
  cross_post:              # 同步到其他平台
    - platform: zhihu
      enabled: true
      adapt_format: true
    - platform: toutiao
      enabled: true
      adapt_format: true
```

## 效果数据

系统运行 3 个月后的核心数据变化：

| 指标 | 引入前 | 引入后 | 改善幅度 |
|------|--------|--------|----------|
| 月均发布文章数 | 15 篇 | 60 篇 | **提升 4 倍** |
| 单篇文章生产时间 | 4-5 小时 | 20 分钟（审核） | **缩短 92%** |
| 日均内容生产时间 | 4 小时 | 40 分钟 | **节省 83%** |
| 粉丝数 | 3 万 | 9.2 万 | **增长 3 倍** |
| 篇均阅读量 | 2,500 | 4,800 | **提升 92%** |
| 月均广告收入 | ¥3,000 | ¥12,000 | **增长 4 倍** |
| 内容原创度 | 100%（手写） | 92%（AI 辅助） | 保持高原创度 |
| 读者满意度评分 | 4.2/5 | 4.0/5 | 略有下降但可接受 |

值得注意的是，读者满意度评分从 4.2 微降到 4.0，说明 AI 辅助内容与纯手写内容之间仍存在细微差距。但综合考虑产量的大幅提升和收入的显著增长，这个权衡是值得的。

一个有趣的发现是：AI 选题的命中率反而高于人工选题。因为 AI 可以同时分析多个平台的数据趋势，能捕捉到人工容易忽略的"起势话题"——即热度正在上升但尚未爆发的话题，这类话题的文章往往能获得最好的传播效果。

## 经验总结

**1. 风格指南是灵魂**

直接让 AI 写文章出来的内容像模板化的新闻稿，读者一眼就能看出不对劲。花时间提炼自己的写作风格指南，并持续优化调整，是区别于"AI 批量水文"的关键。小陈的风格指南已经迭代了 7 个版本。

**2. 人工审核不能省**

即使系统已经很成熟，每篇文章发布前的人工审核环节不能取消。AI 偶尔会出现事实性错误、数据过时或者语气失当的情况，这些需要人眼把关。人工审核的 20 分钟是投入产出比最高的环节。

**3. 保持"人味"的小技巧**

在 AI 生成的内容基础上，小陈会手动添加一些个人化的元素：自己的亲身体验、朋友圈里的真实对话、对某个产品的主观感受等。这些 AI 无法生成的"人味"内容是留住忠实读者的关键。

**4. 发布频率与质量的平衡**

从每月 15 篇提升到 60 篇的过程是渐进的。最初系统输出的文章质量波动较大，通过不断优化 Prompt 和风格指南，逐步稳定在一个可接受的水平后才加大产量。

**5. 多平台分发的注意事项**

同一内容发布到不同平台时需要适配格式和风格。知乎读者偏好深度分析和数据论证，头条号读者更喜欢故事性和实用性。系统会根据平台特点自动调整内容侧重点和表达方式。
